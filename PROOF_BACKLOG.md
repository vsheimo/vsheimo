# Proof backlog

Цель - собрать доказательства, которые усилят Kwork, GitHub-профиль и публичное позиционирование без выдуманных цифр и неразрешенных кейсов.

## Что собрать

### Коммерческие предложения

- Обезличенные КП.
- До/после: слабое КП -> сильная структура.
- Набор блоков конструктора КП.
- Скриншоты или PDF-примеры без клиентских данных.

### Конструкторы и внутренние инструменты

- Скриншоты конструкторов.
- Видео-демо на 1-3 минуты.
- README с логикой работы.
- Схема: входные данные -> процесс -> результат.

### B2B-продажи и sales ops

- Схемы воронок.
- Примеры CRM-этапов.
- KPI-модели.
- Мотивационные схемы.
- Таблицы контроля pipeline.

### AI/Codex-workflow

- Примеры промтов.
- Скриншоты терминала/репозитория.
- GitHub-демо.
- До/после по документам или файлам.
- Видео запуска workflow.

### ШЕЙМО / Vlad OS / внутренние сервисы

- Краткие product brief.
- Схемы экранов.
- README.
- Карта сценариев пользователя.
- Публичные скриншоты без приватных данных.

### Консалтинг и стратегические разборы

- Обезличенные карты проблем.
- Итоговые документы сессий.
- Примеры планов внедрения.
- Отзывы.
- Короткие кейсы в формате "контекст -> проблема -> решение -> артефакт".

## Приоритеты

### Первый приоритет

1. Один сильный обезличенный пример КП до/после.
2. Видео-демо конструктора КП или AI-workflow.
3. Скриншоты ШЕЙМО/Vlad OS/внутреннего сервиса.
4. README с описанием Codex-workflow для документов.
5. 3 коротких отзыва или подтверждения результата.

### Второй приоритет

1. Схема B2B-воронки и CRM-логики.
2. Пример KPI/мотивационной модели.
3. Пример базы знаний.
4. Product brief для ШЕЙМО.
5. Product brief для Vlad OS.

### Третий приоритет

1. Публичный мини-кейс по AI-автоматизации документов.
2. Публичный мини-кейс по упаковке оффера.
3. Публичный мини-кейс по стратегическому разбору.
4. Страница с портфолио-скриншотами.
5. Короткое видео "как я работаю".

## Правило публикации

Каждый proof должен усиливать образ и не создавать юридический, репутационный или конфиденциальный риск. Лучше один аккуратный обезличенный кейс, чем десять мутных скриншотов с лишними данными.
