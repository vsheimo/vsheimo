# Kwork-пакет для профиля супруги

Дата сборки: 2026-06-14. Проход 1 — Codex. Проход 2 — Claude (верификация источников, призмы, финальные тексты, цены, playbook).

Статус: рабочий черновик. Не публиковать без ручной вычитки, реального фото и сверки правил Kwork в личном кабинете.

## Зачем этот пакет

Собрать Kwork-позиционирование для мягкого, умного, начитанного женского профиля, который продаёт учебную помощь, объяснение сложных тем, тексты, презентации, карточки товаров и аккуратную работу с визуалом.

Ключевой образ: не «делаю всё подряд», а «помогаю привести хаос задания, текста, фото или идеи в понятный результат». Интеллект показывается между строк: через способность объяснить, структурировать, увидеть логику предмета и не напугать клиента сложностью.

## Важные рамки

1. Не обещать академическое мошенничество: помощь, разбор, план, оформление, редактура, консультация, объяснение, учебный пакет.
2. Не вводить клиента в заблуждение: если часть работы делает Влад — безопасная подача «работаем в связке» / «редакторская поддержка», а не легенда об одиночном исполнителе.
3. Не использовать парапсихологию как доказательство. Опора — педагогика, когнитивная психология, психология восприятия и доверия.
4. Сначала запускаем 3–4 самых понятных кворка, потом расширяем по фактическим заказам.
5. Цифры цен — гипотезы, калибровать по живым конкурентам. Факты площадки сверять в кабинете перед публикацией.

## Первый запуск

1. Учебная работа: план, структура, оформление, редактура, источники, подготовка к защите.
2. Объяснение темы простым языком (через призму): математика, экономика, логика, школьные и студенческие темы.
3. Презентация или защита: структура выступления, слайды, речь, ответы на вопросы.
4. Карточки товаров: фото, описание, преимущества, структура.
