# Kwork package for spouse profile

Дата сборки: 2026-06-14.

Статус: черновой пакет для проверки Владом и следующего прохода в Claude/Codex. Пакет не публиковать без ручной вычитки, фотографии и проверки правил Kwork.

## Зачем этот пакет

Собрать Kwork-позиционирование для мягкого, умного, начитанного женского профиля, который продает учебную помощь, объяснение сложных тем, тексты, презентации, карточки товаров и аккуратную работу с визуалом.

Ключевой образ: не "делаю все подряд", а "помогаю привести хаос задания, текста, фото или идеи в понятный результат". Интеллект показывается между строк: через способность объяснить, структурировать, задать вопросы, увидеть логику предмета и не напугать клиента сложностью.

## Важные рамки

1. Не обещать академическое мошенничество: формулируем как помощь, разбор, план, оформление, редактура, консультация, объяснение и учебный пакет.
2. Не вводить Kwork-клиента в заблуждение: если часть работы выполняет Влад, безопасная подача - "работаем в связке" или "редакторская помощь", а не легенда об одиночном исполнителе.
3. Не использовать "парапсихологию" как доказательство. Ее можно оставить только как слой восприятия, символов и интуитивной подачи. Доказательная база - педагогика, когнитивная психология, доверие и социальное присутствие.
4. Сначала запускаем 3-4 самых понятных кворка, потом расширяем линейку по фактическим заказам.

## Первый запуск

Рекомендуемый старт:

1. Учебная работа: план, структура, оформление, редактура, источники, консультация.
2. Объяснение темы простым языком: математика, экономика, логика, школьные и студенческие темы.
3. Презентация или защита: структура выступления, слайды, речь, ответы на вопросы.
4. Карточки товаров: фото, описание, преимущества, SEO-ключи, публикационная структура.
