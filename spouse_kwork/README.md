# Kwork-пакет для профиля супруги

Дата сборки: 2026-06-14. Проход 1: Codex. Проход 2: Claude (верификация источников, призмы, финальные тексты, цены, playbook).

Статус: рабочий черновик. Не публиковать без ручной вычитки, реального фото и сверки правил Kwork в личном кабинете.

## Зачем этот пакет

Собрать Kwork-позиционирование для профиля Каган Анастасии: бухгалтерия, налоги, 1С, Excel, ОСВ, акты сверки, взаиморасчёты, маркетплейсы, банковское дело, статистика, теория вероятностей, факторный анализ, базы данных и аккуратный разбор договоров.

Ключевой образ: не «универсальная репетиторша» и не «делаю всё подряд», а человек, который спокойно вытаскивает порядок из цифр, документов, таблиц и учебно-рабочих задач. Интеллект показывается между строк: через точный вопрос, понятную таблицу, видимую логику и честную границу.

## Важные рамки

1. Не обещать академическое мошенничество: помощь, разбор, расчёты, таблицы, оформление, объяснение, подготовка к защите.
2. Не вводить клиента в заблуждение: подтверждённые документы пишем точно, неподтверждённые документы добавляем только после находки.
3. Не использовать парапсихологию как доказательство. Опора: понятность, спокойствие, точные вопросы и доказуемая практика.
4. Сначала запускаем 5 кворков из главного стартового файла: 4 согласованных направления плюс отдельный Excel-кворк.
5. Цифры цен: гипотезы, калибровать по живым конкурентам. Факты площадки сверять в кабинете перед публикацией.

## Первый запуск

1. Бухгалтерские таблицы: ОСВ, акты сверки, дебиторка, кредиторка, взаиморасчёты, учёт/налоги для маркетплейсов.
2. Статистика, теория вероятностей, факторный анализ: расчёты, таблицы, выводы.
3. Банковское дело: учебные и прикладные расчёты, логика, текст.
4. Базы данных, SQL, простые Python/React-задачи: структура данных и понятный учебный/рабочий результат.
5. Excel и автоматизация таблиц: формулы, сводные, склейка файлов, макросы, Power Query, CRM/webhook-синхронизация.

Договоры и протокол разногласий держим как компетенцию профиля, а не как стартовый кворк.
