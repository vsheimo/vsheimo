# Промт для Claude/Codex на следующий проход

Ты получаешь локальный пакет файлов из папки `spouse_kwork/`. Твоя задача - докрутить Kwork-профиль для супруги Влада без потери рамок и без выдуманных достижений.

## Контекст

Профиль нужен для Kwork. Основная подача: умная, начитанная, спокойная девушка, которая помогает с учебными материалами, объяснением сложных тем, презентациями, карточками товаров, фото для web, продающими текстами, таблицами и конспектами.

Важная правда: часть исполнения может делать Влад. Нельзя строить легенду, будто все делает один человек, если это будет вводить клиента в заблуждение. Безопасная версия - профиль супруги как клиентский фронт/авторская роль с редакторской или семейной связкой, если это совместимо с правилами площадки.

## Нельзя

- Нельзя обещать академическое мошенничество.
- Нельзя писать "гарантирую оценку".
- Нельзя выдавать чужие достижения за личные.
- Нельзя использовать парапсихологию как доказательство.
- Нельзя делать массовый скрейпинг Kwork.
- Нельзя копировать тексты конкурентов.

## Можно

- Переписать услуги в более живом стиле.
- Усилить "между строк" образ умной девушки.
- Добавить конкретные формулировки для карточек Kwork.
- Сравнить с конкурентными архетипами по публичным примерам.
- Добавить гипотезы по визуалу и фото.
- Подготовить короткие версии для профиля, обложек, FAQ и быстрых ответов клиентам.

## Что нужно выдать

1. Финальную версию описания профиля: короткая, средняя, длинная.
2. 8-10 готовых кворков с названием, описанием, пакетами, FAQ и вопросами клиенту.
3. Отдельный блок "что запускать первым".
4. Таблицу конкурентных отличий.
5. Рекомендации по фото/обложкам.
6. Список фраз, которые нельзя использовать из-за риска модерации или недоверия.
7. Чеклист публикации на Kwork.

## Стиль

Писать по-русски, живо, без маркетинговой пены. Не "качественно и быстро", а конкретно: что клиент получит в руках, зачем это ему, как снизится тревога, что станет понятнее.

Главная интонация:

> Сложное можно объяснить спокойно. Я помогу разложить задачу на шаги и оставить после работы понятный материал, а не просто файл.
