# 00 Autostart Read First

Status: `MANDATORY_READ_FIRST`

Этот файл читать первым перед любой существенной задачей в этом репозитории.

## Зачем

Не работать из памяти, если рядом уже есть файлы, реестры, скрины, архивы, Kwork-карты, резюме, досье, навыки и чужие проходы.

## Минимальный запуск

Перед действием агент обязан:

1. назвать текущую цель одним предложением;
2. проверить `git status --short --branch`;
3. прочитать актуальные файлы по теме;
4. отделить текущую правду от сырья, истории и гипотез;
5. проверить долги прошлого прохода;
6. выбрать нужные стартеры из этой папки;
7. назначить роли проверки;
8. только потом редактировать файлы или давать финальный ответ.

## Запрещено

1. Не говорить `готово`, если не проверены файлы и долги.
2. Не создавать красивый вывод без evidence.
3. Не стирать и не переписывать чужие live/raw/source файлы.
4. Не использовать `git add .` и `git add -A`.
5. Не трогать `.env`, ключи, токены, auth-файлы, приватные сырьевые архивы без явной причины.
6. Не публиковать raw/private/PII в публичные файлы.
7. Не выдавать `ПРОВЕРИТЬ` за факт.
8. Не создавать отдельный репозиторий без отдельного решения оператора или правила из `04_REPOSITORY_ROUTING_RU.md`.
