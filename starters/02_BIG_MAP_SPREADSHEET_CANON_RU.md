# 02 Big Map Spreadsheet Canon

Status: `MANDATORY_FOR_TABLES_AND_MARKET_MAPS`

Этот стартер включается для Excel, Google Sheets, CSV, рыночных карт, реестров заказов, конкурентов, навыков, профиля, резюме, досье и всего, где оператору нужна большая понятная карта.

## Главный принцип

Одна первая вкладка должна давать картину мира. Остальные вкладки нужны для проверки, фильтрации и источников, а не для ежедневного чтения.

## Обязательная структура книги

1. Первая вкладка: `Карта проекта`.
2. Вверху: короткая навигация и решение на сегодня.
3. Ниже: большие блоки подряд, без прыжков по маленьким вкладкам.
4. Внутри блоков: данные не теряются, но повторы сжимаются.
5. Отдельные вкладки: raw/live/source, канон, источники, долги.

## Правило "ничего не теряем"

Нельзя выбрасывать строки только потому, что они неудобные.

Можно:

1. объединять дубль в одну строку канона;
2. переносить сырой текст в source/raw;
3. помечать `ПРОВЕРИТЬ`;
4. сжимать тавтологию в категорию;
5. оставлять ссылку на исходный файл.

Нельзя:

1. удалять live-слой;
2. переписывать source-файлы под красивый вывод;
3. смешивать даты сбора без поля `дата`;
4. выдавать гипотезу за факт;
5. прятать долг в примечание без owner и next action.

## Видимая таблица

1. Русские заголовки.
2. Без англицизмов в пользовательской зоне, если есть нормальный русский эквивалент.
3. Без символов длинного тире `U+2014` и `U+2013`.
4. Без `RUB`, `руб.` и технических кодов в видимой зоне.
5. Деньги показывать с пробелом тысяч: `1 000`, `10 000`, `100 000`.
6. Один столбец - один смысл.
7. Повторяющийся текст в 3+ строках - сигнал вынести в категорию.
8. Комментарий должен добавлять факт: сумма, риск, источник, срок, решение.

## Минимальные вкладки для Kwork-книги

1. `Карта проекта` - главная большая карта.
2. `Живой слой ДД.ММ` - свежие заказы как отдельный слой.
3. `Канон заказов` - очищенный реестр без потери строк.
4. `Направления` - scoring и решение.
5. `Кворки` - карточки, тексты, статусы, что публиковать.
6. `Источники` - файл, дата, метод, доверие, правило использования.
7. `Долги` - что проверить, кто owner, next action.

## Проверка перед финалом

1. Первая вкладка реально объясняет картину без прыжков.
2. Все source/live/raw слои сохранены.
3. В книге есть лист `Источники`.
4. В книге есть лист `Долги`.
5. Нет длинных тире в видимых листах.
6. Нет англоязычных служебных статусов в главной карте.
7. Есть `ПРОВЕРИТЬ` там, где факт не доказан.
8. Есть эффективная ставка в час там, где речь о деньгах.
